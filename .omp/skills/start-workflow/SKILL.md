# 启动 Workflow

把需求落到一个本地文件，拼装好启动命令，**明确交给用户在 AI session 外执行**。
不要改 workflow 实现，不要改启动参数去重试。

当前 agent 使用 `--tool omp`。不要换成其它工具。

## 硬性约束（必须遵守）

1. **禁止**在当前 AI session 里用 Shell / 终端工具执行 `sddl:start`（或 `start.sh` / `start.cmd`）。
2. **禁止**为「续跑」「审批后继续」再次执行或再次拼装启动命令去跑；审批通过后由**已在外部终端运行的** Python 进程自动进入下一节点。
3. 准备完成后：把**完整可复制命令**展示给用户，并明确说明执行方式（见第 2 节）。

业务项目根执行时，cwd 会作为 `app_root`。命令模板：

```bash
sddl:start --tool omp --file "<PRD 绝对路径>"
```

`--file` 必须是已存在文件的绝对路径。用户要求指定产出目录名时再加 `--name <目录名>`。用户明确要求重来时才加 `--fresh`。

## 1. 确定 PRD 文件

先看上下文里有没有本地 PRD 路径。有就用它，没有再看是不是要从外部系统读。

### 已给出本地路径

用户或当前对话已经给出 PRD 在本机的位置时：

1. 解析成绝对路径，确认该文件存在。
2. 不要再访问 Colla、Jira 或其它系统。
3. 这个绝对路径就是 `--file`。

路径不存在、或给的是目录时，停下来说明情况，不要拼装启动命令。

### 要从 Colla、Jira 或其它外部系统读取

上下文要求从 Colla、Jira 或其它外部系统取需求，且没有可用的本地 PRD 文件时：

1. 用哪一个 MCP、按什么步骤读，只以这次 skill 的输入和项目里已经配置的 rule 为准（例如 Cursor rules、`CLAUDE.md`、`AGENTS.md`、omp rules、`ai-rules`）。
2. 不要猜测 MCP 名字，也不要编写读取步骤。MCP 由用户事先配好。
3. 输入和 rule 都没有说明怎么读时，停下来问用户，不要拼装启动命令。
4. 读到正文后，写入业务项目根的 `docs/requirements/<标识>.md`。目录不存在就创建。同名文件直接覆盖。
5. 标识优先用需求编号；没有编号时用标题，只保留字母、数字、中文和 `-`。
6. 正文为空时停下来，不要拼装启动命令。写入后的绝对路径就是 `--file`。

### 两边都没有

问用户要本地 PRD 路径，或要读取的外部需求来源。不要拼装启动命令。

## 2. 交出命令（到此结束，不要执行）

用上一步的绝对路径拼好**一条完整命令**，原样展示给用户（单独代码块，便于复制），然后用下面这种说明收尾，**停止本 skill，不要调用任何执行命令的工具**：

> 请复制下面的命令，任选一种方式执行（不要在当前 AI 对话里跑）：
>
> 1. **新开一个终端**，`cd` 到业务项目根后粘贴执行；或
> 2. **退出 / 结束当前 AI session** 后，在系统终端里执行。
>
> Workflow 必须在 AI session 外的终端里跑，这样编排进程才能接管交互节点并自动续跑。审批通过后无需再执行本命令。

示例回复形态：

```bash
sddl:start --tool omp --file "/absolute/path/to/prd.md"
```

（可按用户要求加上 `--name ...` / `--fresh`。）
